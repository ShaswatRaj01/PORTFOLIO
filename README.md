# Shaswat Raj Singh — 3D Interactive Portfolio

## Run locally
Because this is a static site, the easiest option is:

1. Extract this folder.
2. Put your certificate PDFs inside `certificates/`.
3. Rename them to the filenames referenced in `index.html`, or edit the `data-cert` values.
4. Open `index.html` in a browser.

For best results, use a local server (for example VS Code Live Server).
