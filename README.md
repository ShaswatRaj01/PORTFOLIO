## GitHub Pages
1. Extract the ZIP.
2. Open your `PORTFOLIO` GitHub repository.
3. Upload/replace `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Commit the changes.
5. Go to **Settings → Pages**.
6. Keep **Deploy from a branch → main → /(root)** selected.
7. Save.
8. Wait for GitHub Pages to finish deploying.
9. Open your Pages URL.

The skills section uses Simple Icons through CDN URLs, so an internet connection is needed for those logos.
